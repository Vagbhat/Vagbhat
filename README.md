## Featured Projects

### [Self-Correcting NLQ-to-Query Agent](https://github.com/Vagbhat/Self-Correcting-NLQ-to-Query-using-Agentic-AI)

A LangGraph prototype for translating natural language questions into SQL and Cypher. The notebook explores schema-based grading, conditional query regeneration, and execution against PostgreSQL and Neo4j; a separate Streamlit interface demonstrates query generation and execution.

**Stack:** Python, LangGraph, LangChain, Ollama, Groq, PostgreSQL, Neo4j, Streamlit

### [Semantic Drift Auditor](https://github.com/Vagbhat/Semantic-Drift-Auditor)

A Streamlit application that tracks how software requirements change during repeated LLM refinement. It combines SBERT embeddings and cosine similarity with configurable drift thresholds, trend charts, and CSV exports to flag changes for human review.

**Stack:** Python, Streamlit, Sentence Transformers, Groq, Llama 3.3, Scikit-learn, Pandas

### [Faithful Benchmark for Information-Seeking Dialogue](https://github.com/Vagbhat/Faithful-Benchmark-for-Information-Seeking-Dialogue)

An academic project exploring whether generated dialogue is supported by its source knowledge. It includes BERT classification using BEGIN and VRM taxonomies, alongside GPT-2 knowledge-grounded generation experiments.

**Stack:** Python, BERT, GPT-2, NLP, Jupyter, Wizard of Wikipedia
